2.221.0 — 18 November 2026

  • Copyright metadata in WebSite schema. Added copyrightYear, copyrightHolder (reference to the Organization node) and copyrightNotice to the WebSite JSON-LD block on every page, reinforcing knowledge-graph attribution and licensing metadata.

2.220.0 — 18 November 2026

  • Image sitemap titles fixed. The XML image sitemap was deriving image:title from URL slugs (e.g. "Bill Of Sale Template.Html") for OG share cards. It now reads each page's actual <title> so Google Images and Pinterest see the human-readable headline.

2.219.0 — 18 November 2026

  • Referrer policy + generator meta. Added <meta name="referrer" content="strict-origin-when-cross-origin"> so cross-origin navigations only send the origin (not the full URL path) as the Referer header — protects long-tail query parameters (e.g. from /search/) from leaking to third parties linked from the page. Added <meta name="generator" content="Clausery"> for CMS identity.

2.218.0 — 18 November 2026

  • Pricing schema eligible for product rich snippets. Added validThrough (1 year) and availability:InStock to all pricing Offer schemas, reviewCount alongside ratingCount on homepage/site-wide AggregateRatings (required for software rich snippets), and attached the 4.8★ AggregateRating to the site-wide WebApplication node.

2.217.0 — 18 November 2026

  • Organization sameAs expanded. Added the Clausery GitHub organisation URL (github.com/getclausery) and the npm package profile (npmjs.com/package/clausery) to the Organization JSON-LD sameAs array on the homepage and the site-wide schema block. More authoritative identity links help search engines and knowledge-graph resolvers disambiguate this Clausery (open-source document generator) from clausery.ai (enterprise compliance software).

2.216.0 — 18 November 2026

  • rel=noopener on changelog GitHub links. Added rel="noopener" to the two "git log" links to prevent the opened tab from reaching window.opener and to suppress the Referer header on cross-origin navigation.

2.215.0 — 18 November 2026

  • SEO title pass on short pages. Expanded seven short/under-optimized <title> tags (Contact, FAQ, Security, Guides hub, Roadmap, Status, Security Deposit Return guide) to fill the 60-char SERP budget with high-intent keywords.

2.214.0 — 18 November 2026

  • Filter input announces result count to screen readers. Added aria-describedby="tpl-q-count" and aria-controls="tpl-groups" to the /templates/ filter input so screen readers associate it with the live "N of X templates match" status region and announce the count as the user types. Gave the status <p> a matching id (it already had role="status" aria-live="polite" from earlier passes, just lacked the programmatic connection).

2.213.0 — 18 November 2026

  • Focus ring on bare <button> elements. Added button:focus-visible to the global focus-ring selector so icon-only and text buttons that don't carry the .btn class (mobile hamburger menu, ⌘K search button, welcome-bar dismiss, print/share buttons on guide pages) now also show the 2 px keyboard focus ring instead of relying solely on the browser default (which is invisible in High Contrast mode on some platforms).

2.212.0 — 18 November 2026

  • ⌘K keyboard shortcut advertised to screen readers. Added aria-keyshortcuts="Control+K Meta+K /" to the nav-search button so screen readers announce that ⌘K, Ctrl+K and / open the command palette. The ARIA aria-keyshortcuts attribute doesn't change behavior — it only exposes the existing shortcut to assistive technology.

2.211.0 — 18 November 2026

  • Print CSS: hide release pill and "updated" badge. Added .release-pill and .card-updated to the print-media-query exclusion list so the version banner, pulsing dot and "Updated" corner badge on template cards don't appear on printed/PDF copies of pages (useful for the printable invoice and contract templates people export to PDF).

2.210.0 — 18 November 2026

  • Fix: Enter on /templates/ filter focuses the card itself. The v2.209 Enter handler used .feature a to look for a nested link, but template-library cards are <a class="feature"> themselves — focus was never moving. The selector now targets .feature:not([hidden]) directly so Enter reliably moves focus to the first matching template card.

2.209.0 — 18 November 2026

Pressing Enter in the /templates/ filter input now moves focus directly to the first visible matching template link, so keyboard users don't have to Tab past the filter, status line and section headings to reach the result they typed for.
