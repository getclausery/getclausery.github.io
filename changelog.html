2.100.0 — 3 November 2026

  • Responsive UI across every device size. The app stylesheet now has four viewport tiers with proper breakpoints instead of the previous single 800 px cutoff: very small phones (≤360 px), phones (≤600 px), phablets/tablets (601–900 px), and mid/large desktops (901 px+). Key changes by size:
  • Phones ≤600 px. Fluid clamp()-based headings so h1 never wraps awkwardly; inputs forced to 16px to stop iOS Safari zooming on focus; card/toolbar/button padding tightened; card action rows, interview navigation and modal actions stack and stretch so primary CTAs are full-width (no tiny squeezed buttons); KV (key/value) summary lists stack vertically instead of leaving a cramped column; the drafts table and history list scroll horizontally inside their card so they never force a page-wide horizontal scroll; modal dialogs become bottom-sheets that slide up from the bottom of the screen with proper safe-area padding; the ⌘K quick-jump palette also becomes a bottom sheet; the bottom tab bar uses env(safe-area-inset-bottom) so it sits above the iPhone home indicator; toast notifications shift up above the tab bar.
  • Tablets / phablets 601–900 px. Two-column grids return, card grids use a 220 px minimum for three-across on larger tablets, tables still horizontally scroll, toasts sit above the tab bar.
  • Landscape phones. The bottom tab bar switches from icon+stacked-label to icon+inline-label so all four entries fit without crowding, and main-content bottom padding eases since the bar is shorter.
  • Touch vs mouse. Hover effects (card lift, button translateY) are now gated behind @media (hover: hover) and (pointer: fine) so they don't "stick" after a tap on touch devices.
  • Overflow prevention. body { overflow-x: hidden } applied globally; min-width:0 extended to every grid/flex container that could previously pin its parent wider than the viewport (toolbar, tabs, key-value lists, card actions, repeat-row heads, preview wraps, modal actions); replaced the over-aggressive global * { max-width: 100% } rule (which broke SVG icons and decorative elements) with a targeted list of replaced elements and form controls that actually need capping.
  • Top bar. Brand uses clamp() font sizing, status text gets text-overflow: ellipsis and a 60 vw max so it never pushes the brand off-screen; at ≤380 px the top bar shortens to 52 px and the brand/icon shrink further.
  • Copy-guard banner. On pages where the unlicensed-rebrand banner appears, the sticky top bar, stepper and toasts are offset down so the banner never covers them.
