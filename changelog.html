1.65.0 — 24 October 2026

  • Tightened the marketing-site and 404 CSP + preconnect lists down to only what those pages actually load:
    • Removed getclausery.goatcounter.com from img-src/connect-src and its preconnect/dns-prefetch. The anonymous GoatCounter event pixel only fires inside the app (document made, draft started, plan chosen); marketing pages run Cloudflare Web Analytics only and never hit GoatCounter.
    • Removed api.lemonsqueezy.com from marketing connect-src and its preconnect/dns-prefetch. Marketing pages only link to the hosted checkout with ordinary <a href> (top-level navigation, not a fetch or XHR), so they never make a same-tab request to the LemonSqueezy API; the app shell, activate page and purchase runtime still preconnect and allow-list it, since those pages call the license-key endpoint directly.
    App-shell CSP/preconnects are unchanged; that is where the license-key check and anonymous event count actually fire.
