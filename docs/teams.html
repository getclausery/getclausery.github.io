Teams & template packs

Clausery has no central server, so sharing works the way your firm already shares files.

Template packs

A pack is a JSON file holding one or more templates: the Word document, the questionnaire and its logic. Export one from a template's menu (Export as template pack). A workspace backup (Settings → Your data) is different: it also contains drafts, and it is restored with Restore backup, not Import pack.

Put the pack on the shared drive or in your document-management system. Colleagues import it from the Templates page. Importing a pack that contains a template they already have updates it in place, so versioning is as simple as re-exporting after changes.

Suggested practice: keep an "approved templates" folder with the current pack, and a changelog next to it. One person owns edits; everyone else imports.

Drafts stay personal

Drafts and their answers live in each person's browser. To hand a matter over, export the draft's answers (Export answers on the review step) and let the colleague import them into a draft of the same template.

Worked rollout: update an approved service agreement

Suppose one owner maintains your service agreement and three colleagues draft from it. Review the wording change in Word, use Replace document on the existing template, check the questions and export a new pack. Keep a dated filename and a short change note in the approved folder; do not rely on an email subject as the version record.

  1. Before importing, each colleague downloads a workspace backup so their current state is recoverable.
  2. They choose Import pack on Templates and select the approved JSON file. A pack with the same template ID updates that template; a newly created template with a different ID is a separate item, even if its name looks identical.
  3. They generate a fictional example and inspect both the changed paragraph and the optional terms. Importing a file is not proof that the new wording is correct.
  4. Keep existing signed output separately. Regenerating an old draft can use the updated template, so review the result rather than treating it as an untouched historical copy.

What a pack does not share

A pack includes the selected templates and their Word files, questions and rules; it does not include drafts, their answers or a licence. Exporting a pack is a Pro feature. Imported templates count as your own templates, so a Free workspace's own-template limit still applies.

For a single matter, hand off an Export answers (.json) file to a colleague using the intended template. Review it before generating. Use client intake forms when a client needs the questionnaire, not a full pack. None of these files creates live co-editing or background synchronisation between browsers.

Licensing a team

The online Team plan covers five named users. Share only the private Open Clausery access link from your receipt with those licensed users; each opens it to activate their browser automatically, with no key to copy. Up to fifteen browser profiles can be activated. Settings → Advanced activation → Remove from this browser frees an unused activation without cancelling the subscription. Additional named users are $9 each/month by request before buying. Teams that need no network can ask for an offline license.

Enterprise deployments

Firms that want the app on their own domain (for example draft.yourfirm.com) or intranet can self-host it: it is a folder of static files. See Self-hosting.
