Backups & data

Where data lives

Everything is in your browser's IndexedDB for this site: templates (with the .docx bytes), drafts and settings. Different browsers and profiles on the same computer have separate workspaces.

Backups

Settings → Your data → Download backup saves a single JSON file with all templates, documents, drafts and settings (except the license key and the encryption passphrase). Restore it with Restore backup, choosing Merge or Replace everything.

Backups are not encrypted, even when the workspace is. Store them in an appropriately protected location with access limited to people who should see the client information. Do not put a real backup in a public repository or send one as an ordinary support attachment.

A workspace backup carries templates, their source Word files, drafts and supported settings. Keep downloaded finished Word files, signed PDFs and signature evidence separately; the backup is not a copy of every file in your Downloads folder. For sharing only templates, use a template pack instead.

Moving to a new computer

Download a backup and restore it on the new machine. Open the Open Clausery button in your receipt email there to activate your paid plan automatically. If you use the encrypted workspace, turn it on again on the new machine with the passphrase of your choice.

Worked recovery test before you clear a browser

Use fictional data to rehearse recovery before a browser replacement or computer move. Saving a file is only the first half of a backup process; test that the templates and answers can actually be restored.

  1. On the source browser, open Settings → Your data, note the displayed template and draft counts, and choose Download backup. Keep the dated JSON file intact.
  2. Open Clausery in a separate browser profile intended for the test. It has its own workspace; merely visiting the same website does not synchronise data.
  3. Choose Restore backup, check the displayed counts and select the appropriate restore mode.
  4. Open a known draft, check its answers and generate a sample .docx. Also check a custom template, not only a library starter.
  5. Confirm the protected backup and any required finished documents are available before erasing or retiring the source browser.

Merge versus Replace everything

ModeWhat happensBefore choosing it
MergeAdds records and updates records with matching IDs; unrelated existing records remain.Download a current backup first. Merge is not a conflict-resolution tool and can replace a matching record's older or newer contents.
Replace everythingClears current templates, source files and drafts before importing the backup records.Use only when intentionally replacing this workspace, after preserving anything you need from it.

Neither option transfers the encryption passphrase or a paid activation. Activate the new browser separately if needed and configure its workspace encryption again. If a JSON file is rejected, preserve the original and check that it is a workspace backup, not an answers file or template pack. Do not repair a real client backup by guessing at its structure.

Protected storage

Browsers may evict site data under storage pressure. Settings shows whether this site's storage is protected and lets you request it; installing the app (browser menu → Install) usually grants it permanently.

Encrypted workspace

With encryption on (Pro), templates, documents and drafts are encrypted at rest with AES-256-GCM using a key derived from your passphrase (PBKDF2-SHA256, 600,000 iterations). The key exists only in memory while the workspace is unlocked; it locks after the inactivity period you choose. There is no recovery: a forgotten passphrase means the data is unreadable, which is the property you want from encryption. Keep a backup.

Erasing

Erase workspace deletes everything Clausery stored in this browser. Clearing the site's data in the browser settings does the same.
