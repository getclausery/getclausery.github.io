How to automate a Word template without uploading it anywhere

Published 26 September 2026 · Updated 24 October 2026 · Reviewed by Clausery editors · Automating Word templates

If you copy last month's letter and hunt for every name and date to change, this guide is for you. It takes about ten minutes for your first template.

1. Pick a document you draft often

Start with something you produce at least weekly: an engagement letter, an NDA, an offer letter. Open your best recent version in Word.

2. Replace the details that change with tags

Select a detail that changes, such as the client's name, and type a tag in curly braces instead: {client_name}. Use the same tag everywhere the same detail appears. Use letters, digits and underscores, and choose descriptive names; Clausery guesses the question type from them, so {start_date} becomes a date picker and {retainer_amount} a money field.

This Agreement is made on {effective_date} between {client_name} and {firm_name}.

3. Make optional paragraphs conditional

Wrap text that only sometimes applies in a section: {#has_retainer} before it and {/has_retainer} after it. Clausery asks a yes/no question and removes the paragraph when the answer is no. For the opposite case, use {^has_retainer}…{/has_retainer}.

4. Repeat lists

For parties, attorneys, deliverables or line items, wrap one item in a loop: {#attorneys}{name}, {role}{/attorneys}. The questionnaire lets you add as many as you need. In a table, put the opening tag in the first cell of a row and the closing tag in the last cell.

5. Save as .docx and drop it into Clausery

Open Clausery and drop the file on the Templates page. Every tag becomes a question. Rename questions, add help text and group them into sections in the designer, then click New draft.

6. Generate the document

Answer the questions and download the finished .docx, or print to PDF. Your formatting is kept exactly, and nothing was uploaded at any point.

Before you start: clean the document

  • Use real heading styles. Headings, lists and tables should use Word's built-in styles, not bold text and manual numbering. The questionnaire inherits that structure.
  • Remove tracked changes and comments. They can leak into the template and confuse the tag scan.
  • Keep text out of text boxes and shapes. Word stores that text separately, and tags inside it are easy to miss.
  • Check the headers and footers. Tags work there too, which is useful for reference numbers and dates, but only if the header is not linked to a previous section you did not intend to change.
  • Save a copy. Keep the original Word file as your master; upload a copy to Clausery.

Common tag mistakes

  • A space inside the braces. { client_name } is not the same as {client_name}.
  • Two names for one answer. {client} and {client_name} create two questions. Pick one name and use it everywhere.
  • A closing tag that does not match. {#has_retainer} must close with {/has_retainer}, not {/retainer}.
  • Typing over an existing tag. Word can split a tag across formatting runs. If a tag stops working, delete it and type it again in one go.

A before-and-after example

Before: "This Agreement is made on 14 March 2026 between Acme Ltd and J. Patel." After: "This Agreement is made on {effective_date} between {client_name} and {firm_name}." The sentence, styles and spacing stay the same; only the details that change become tags.

When not to automate

Do not automate a document you send once, or one whose wording changes every time. Automation pays back when the document is long, the wording is stable and the details change per client. Start with the document you send most often; it is usually the one with the clearest structure and the most mistakes when edited by hand.

How long it takes

Most templates take ten to twenty minutes for the first version: tag the changing details, add one or two conditional sections, upload and answer the questionnaire. The first draft of a complex contract can take an hour. After that, each document takes minutes and the wording stays consistent.

Want to see a finished example first? Open one of the free templates, or read the full template syntax. If you get stuck on a conditional section, the conditional clauses guide has the patterns and the troubleshooting list.

Questions

Do I need to change the formatting of my Word document?

No. Clausery keeps the styles, numbering, headers and letterhead you already use, because it fills the original .docx rather than recreating the page. Use Word styles consistently so the questionnaire can group the sections sensibly.

Can I automate a scanned PDF?

Not directly. A scan is an image with no text structure. Convert it to Word with OCR first, check the result against the original, then add tags to the Word file.

What happens if I delete a question in the designer?

The tag stays in the template and the question is regenerated the next time the file is scanned, unless you remove the tag from the Word file. Edit the master document, then upload it again.
