Roadmap

Reviewed by Clausery editors · 28 October 2026 · 1 min read

What has shipped recently, what is being worked on now, and how to influence what comes next. Every shipped item is in the changelog; everything else is tracked in public GitHub issues.

Recently shipped

  • v2.32.0 — 14-day free Pro trial with no card, 30-day money-back guarantee, refined plan cards, and the current UI/UX polish pass. Full changelog →
  • Online checkout through Lemon Squeezy with automatic activation (no key to copy).
  • Origin-guarded service worker, per-file attestation manifest, and other anti-clone / provenance protections.
  • Client intake forms, encrypted workspace (AES-256-GCM), and template packs for teams.

In progress

Tracked in public GitHub issues — votes and comments there help prioritise:

  • More templates requested by users (see template requests).
  • Additional invoice presets for more trades and countries.
  • Small UX polish drawn from the frequently asked questions.

How to influence it

  • Request a template. The most-requested documents are built first. Email from the contact page.
  • Upvote or comment on an issue. Open issues at GitHub are read and triaged.
  • Report a bug. Problems that affect document correctness take priority over everything else.

There is no separate backlog tool. The changelog, this page and the GitHub issue tracker are the only places work is tracked.

Common questions

When do features ship?

The roadmap lists planned work in priority order with rough status (Planned / In progress / Shipped). Dates are estimates — Clausery is a small team and bug fixes or security work can pull items forward or push them back.

Can I vote on what is built next?

Yes. Email getclausery@gmail.com with what you need and why; customer requests are the main input to prioritisation.

Are shipped features removed from the roadmap?

Yes. Shipped items move to the changelog with their version number and release date.
