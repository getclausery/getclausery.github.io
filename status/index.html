Status

Clausery is a static site served by GitHub Pages, with document generation running in your browser. There is no application server to go down, so the only things that can fail are the page hosting and the license check.

What to do if something looks down

  1. Reload twice. The service worker updates in the background; a second reload picks up the latest version.
  2. Check GitHub Status. Pages and releases are served from GitHub.
  3. Check open issues. If something is broken it will be there, often within minutes.
  4. Email support. Messages are read by a person, usually the same day.

There is no third-party status dashboard. This page and the public commit history are the source of truth: every release, every fix, and every open issue is visible at the repository.
